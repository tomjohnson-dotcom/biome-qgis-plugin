about=Biome is a comprehensive Biodiversity Net Gain (BNG) habitat mapping plugin for QGIS. Stylised EPSL species icons are derived from game-icons.net (Lorc, Delapouite) under CC BY 3.0.

    It supports the full statutory BNG workflow under Schedule 7A of the Environment Act 2021, including:

    • Baseline and proposed habitat mapping — area habitats, hedgerows, watercourses and individual trees
    • Automatic pairing of baseline and proposed features with retention/enhancement categories
    • BNG unit balance summary (area, hedgerow, watercourse and tree units)
    • De minimis check — geometric gross loss calculation against statutory thresholds (25 m² / 5 m)
    • Overlap warning — the Layers panel flags habitat polygons that overlap within a layer (double-counted area)
    • Feature Manager — view, edit, reshape, delete and restore features with a deleted feature bin
    • Measurements tab — area/length labels, loss layer visualisation and quick measure sketches
    • Desk Study tab — designated sites, priority habitats, ancient woodland, TPOs, GCN risk zones and LPA finder
    • Final map export and blank statutory BNG metric export
    • Feature Mapper for ecological features (ponds, PRF, fencing, bat boxes, etc.)
    • Field survey import from CSV/spreadsheet
    • Photo documentation tab

    Data is stored in a GeoPackage alongside the QGIS project file. Requires a saved .qgz project to function.
